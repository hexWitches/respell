# re:spell

Group project for the Usability and User Experience 2025/26 course.

---

Developed for the Usability and User Experience challenge *Help People Help People*, the project reimagines remote booking assistance for older adults using the [PugliaSalute portal](https://www.sanita.puglia.it/).

By making the booking flow clearer, more predictable, and easily reversible, the redesign empowers seniors to complete tasks autonomously – replacing frustration and credential-sharing with mutual confidence.
